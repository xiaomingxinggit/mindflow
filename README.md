# Mindflow · 无限白板

一个面向个人桌面的本地白板。用 Markdown 记录完整想法、画草图、添加图片，再用箭头连接关系或展示数据流。使用 React、TypeScript、Vite 和 `@excalidraw/excalidraw@0.18.1`，保留 Excalidraw 原生中文界面，无需后端或账号。

## 启动

需要 Node.js 22.12+。在项目目录运行：

```powershell
npm ci
npm run dev
```

打开终端显示的地址，默认是 `http://localhost:5173`。依赖已安装时直接运行 `npm run dev`。

```powershell
npm run build   # TypeScript 检查并构建到 dist/
npm run lint    # 使用 Oxlint 静态检查
npm run preview # 预览生产构建
```

开发和构建会自动将编辑器字体复制到 `public/excalidraw/fonts/`，页面从本站加载字体。该目录是生成资源，不提交到 Git；更换依赖或全新安装后无需手动下载字体。

## 画布操作

- 顶部工具条提供矩形、菱形、椭圆、箭头、线条、画笔、独立文字和图片等工具；更多工具包括画框、橡皮与激光笔。
- 双击空白处、形状或连线标签进入原位 Markdown 编辑；支持中文多行，节点和便签随内容增高。箭头可绑定形状，移动形状后连线跟随。
- 点击、框选或按住 Shift 多选元素。可移动、缩放、旋转、复制、组合、锁定、对齐、分布和调整图层；选中后使用原生属性面板修改颜色、填充、线条、字号等样式。
- 使用平移工具或按住空格拖动画布。左下角提供缩放、适应画布与撤销 / 重做；菜单保留主题、网格和快捷键帮助等原生设置。
- 图片可通过工具选择、拖入或粘贴。应用的“便签”入口会在视口中创建空白浅黄色便签，双击即可输入；首次文字为 16px，距左上边缘 16px，之后按普通图形编辑、移动或复制。
- 右侧素材库可保存选中的元素，之后重新插入，也支持原生素材库文件导入导出。
- 文件菜单的搜索或 Ctrl / Cmd + F 可查找画布中的文字。
- 文件菜单的“命令面板”或 Ctrl / Cmd + / 可打开命令搜索，输入中文筛选后，用方向键选择、Enter 执行、Escape 关闭。

绘图工具和快捷键沿用原生编辑器。文字编辑期间，快捷键交给原位编辑器，不触发画布删除或绘图。常用操作如下，完整列表可从帮助菜单查看：

| 快捷键 | 操作 |
| --- | --- |
| V / H | 选择 / 平移工具 |
| R / D / O | 矩形 / 菱形 / 椭圆 |
| A / L / P / T / E | 箭头 / 线条 / 画笔 / 文字 / 橡皮 |
| 按住 Space | 临时平移画布 |
| Ctrl / Cmd + A | 全选 |
| Ctrl / Cmd + C、V、D | 复制、粘贴、创建副本 |
| Ctrl / Cmd + G | 组合 |

| Delete / Backspace | 删除所选内容 |
| Ctrl / Cmd + Z | 撤销 |
| Ctrl / Cmd + Shift + Z | 重做 |
| Ctrl / Cmd + F | 搜索画布文字 |

## 连接想法

鼠标悬停或单选矩形、菱形、椭圆和便签时，四边出现连接点。拖动连接点靠近另一节点，
目标高亮后释放即可连接；吸附范围为屏幕上的 24px，缩放后仍可操作。连接使用原生绑定，
移动或调整节点时保持关联。

拖到空白处释放会预览一个当前风格的新节点，并立即进入文字输入。输入中文或 Markdown 后，
按 Ctrl / Cmd + Enter 或点击外部完成，节点、文字和连线一起提交，一次撤销即可移除。
Escape 取消、短点击连接点或结束空白内容都不会留下半成品。

顶部第 5 项箭头工具（A）从节点起笔时采用相同规则；从空白处起笔仍可自由画箭头。
文字、图片和画笔不自动变成连接节点。

## 原位 Markdown

节点、便签、独立文字和连线标签使用同一个原位编辑器。双击内容即可编辑，也可选中文字或
包含文字的元素后点击“编辑内容”。支持标题、粗体、斜体、删除线、链接、引用、列表、任务列表、
代码、表格、图片，以及 `$…$` 行内公式和 `$$…$$` 块公式。可以直接粘贴一段 Markdown，
在表格单元格中修改内容，在编辑状态勾选任务；公式提供源文编辑与预览。

编辑区域背景透明，没有外框和阴影，沿用画布及节点底色。双击位置放置光标，直接修改
已有内容；仅打开再关闭或撤销到初始内容时，保留原 Markdown 写法。末尾的代码或公式块
可用向下方向键退出，继续输入正文。

Enter 换行，Ctrl / Cmd + Enter 或点击编辑区域外部完成，Escape 取消。中文输入法组词时
不会误触完成。一次完成进入原生撤销历史，编辑中的草稿不写入自动保存。

内容完整展开，自动计算高度，没有固定高度的内部滚动区。选中元素后，在“文字宽度”中输入
宽度并确认，可调整换行与高度；连线标签单独调宽，不需要拉长箭头。普通文字使用系统无衬线字体，
代码使用系统等宽字体，字号和文字颜色沿用画布属性。节点也可拖动原生角点调宽，内容重新换行，
高度随完整内容调整；原生字号调整同样更新文字与节点尺寸。

编辑框右上方的图片按钮可上传本地图片，也可直接粘贴图片。上传后的资源随画布保存在本地，
不依赖临时地址；图片还可使用 Markdown 地址引用。外链无法加载时显示占位，可重新编辑地址。

例如，双击节点后粘贴下列内容，即可继续在原位置修改表格与公式：

```markdown
## 下一步

- [ ] 验证一个想法
- [x] 整理已有材料

| 方向 | 状态 |
| --- | --- |
| 原型 | 进行中 |

投入与结果：$y = 2x + 1$

$$
E = mc^2
$$
```

## 连线流动效果

新连线默认静态。单选箭头或普通线条，在“流动效果”面板开启后，小圆点沿实际线路循环流动，
颜色跟随线色；速度滑杆对当前连线独立生效。默认速度为 70，范围为 20–180 个画布单位 / 秒。
拖动滑杆即时预览，释放时整步提交，开关和速度都可撤销 / 重做。

普通线与只有终点箭头的线从起点流向终点；只有起点箭头时反向流动，双端箭头双向流动。
文字标签遮挡圆点，表格、图片和公式保持可读。动画跟随路径、旋转、平移和缩放；
每帧只更新展示层，不反复触发自动保存。没有开启的线不运行动画，页面进入后台时停绘。

## 画布风格

右上角“画布风格”提供两个选项，文件菜单和命令面板也可切换：

- **现代风格**为默认选项，使用规整圆角、浅紫色实心节点、柔和紫灰描边和深色文字。
- **系统风格**使用 Excalidraw 的手绘轮廓与斜线填充。两种风格均默认使用操作系统无衬线字体，新建普通文字默认 18px，便签保留暖色。

切换会统一当前画布全部元素的样式，并设置后续绘制的默认值；已有 Markdown 原文、文字宽度、字号、连接关系、分组、图片和流动配置保留。画布有内容时，一次切换可整步撤销 / 重做，风格选择与新建默认值随之恢复。空画布上的切换只改变默认偏好，没有文档元素变化，因此原生撤销不会恢复这次空画布切换。

切换后仍可在原生属性面板手动修改颜色、字号等属性，应用不会持续覆盖手动修改。风格选择和绘图偏好会随当前文档本地保存，新建画布沿用当前选择。打开原生文件保留文件中的元素样式；需要统一外观时再切换画布风格。首次恢复没有风格记录的旧白板时，会统一为现代风格。

矩形、菱形、椭圆、便签、文字和画笔分别记住自己的描边与填充颜色，线条和箭头共用一组颜色。
切换工具时恢复该工具上次使用的颜色，刷新后仍保留；显式切换画布风格会重置这些颜色偏好。

## 保存与备份

左上角可以编辑文档名，并查看“保存中 / 已保存 / 保存失败”状态。场景、图片、名称、主题、视口、画布风格和绘图偏好自动保存到当前浏览器的 IndexedDB；素材库也在本地保存。刷新后恢复当前文档。撤销历史由原生编辑器管理，只在当前页面会话内保留。

通过原生文件菜单或 Ctrl / Cmd + S 保存 `.excalidraw` 文件作为备份，之后用“打开”恢复；也可在命令面板搜索“下载画布文件”直接下载，或搜索“打开原生画布文件”选择备份。文件包含便签、绑定文字、Markdown 原文、指定宽度、本地图片资源和各连线的流动设置；只被 Markdown 引用的本地图片也会保存。保存失败时仍可使用文件导出。

导出支持 PNG、SVG 和复制为图片，使用同一套富内容渲染链路，连线导出为静态图。SVG 中普通图形仍是矢量，Markdown 内容以嵌入的位图呈现，不是可单独编辑的矢量文字；需要继续编辑原文时使用 `.excalidraw` 备份。该文件在上游 Excalidraw 中保留可读文本后备，不保证提供相同富编辑体验或播放本项目流动效果。

首次打开且没有新白板记录时，应用会读取旧 `mindflow-flowchart-v1` 并转换节点、文字、颜色和连线；原 localStorage 值保持不变。旧版 Mindflow JSON 也可以通过专用导入入口转换，旧折线 / 曲线按原生箭头近似恢复。无效旧文件会显示错误并保留当前内容；已移除的思维导图和系统架构格式不再导入。

本地数据按浏览器和地址隔离，例如 `localhost` 与 `127.0.0.1` 是两个保存空间。清理站点数据、切换浏览器或使用无痕窗口可能失去本地内容，请定期保存 `.excalidraw` 备份。当前是单文档本地产品，未接入协作、云同步、账号、Plus 或 AI 服务。

稳定包暂未提供官网的新便签工具，因此便签使用普通形状和绑定文字；命令面板由项目提供常用工具与文件命令。旧版曲线 / 折线路径为近似转换。

## 开发说明

原生编辑核心负责绘制、选择、属性编辑、视图、素材库和历史；应用负责本地工作区、连接手势、Markdown 原位编辑、连线展示动效、风格预设与旧数据转换。改造范围见 [白板实施方案](docs/canvas-redesign-plan.md)，风格设计见 [画布风格选项](docs/visual-styles.md)，本轮设计、适配取舍和实际验收见 [连接、Markdown 与数据流](docs/thought-flow-enhancements.md)。

`src/systemFont.ts` 为锁定的 Excalidraw 0.18.1 适配字体槽位 2，将 canvas、就地编辑和导出使用的字体名称解析为 `system-ui`；保留 `FONT_FAMILY.Helvetica === 2`，不修改依赖包文件。升级编辑器时需重新核对字体解析及文字测量行为。

Markdown 编辑使用 Milkdown Crepe 7.22.3；展示由 markdown-it、KaTeX、DOMPurify 和 html-to-image 生成缓存。
`scripts/excalidraw-rich-text.ts` 在 Vite 加载官方 0.18.1 ESM 时加入少量原生渲染、文字入口、
绑定和资源序列化适配，开发与生产使用同一套路径，不手改 `node_modules`。适配器检查版本及源码锚点，
升级 Excalidraw 时需重新核对这些位置。
