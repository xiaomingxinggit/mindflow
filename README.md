# Mindflow · 动态思维导图

用 React + TypeScript + Vite + React Flow 构建的流程图、思维导图编辑与架构演示项目。

## 流程图

首页默认打开流程图（`/#flowchart`）：

- 左侧图形库提供「开始 / 步骤 / 判断 / 结束」，点击或拖入画布添加。
- 拖动节点调整位置，从节点边缘的圆点拖到另一个节点的圆点创建箭头连线。
- 右侧属性栏编辑节点文字、形状和配色；选中连线可修改分支文字及折线 / 曲线 / 直线样式。
- 选中后点击「删除」或按 Delete / Backspace；删除节点时同时删除关联连线。
- 选择工具支持拖拽框选，平移工具（H）或按住空格可拖动画布；滚轮缩放，右下角可适应全部节点。
- 顶部可修改文档名、新建、导入和导出 JSON。支持撤销 / 重做、复制节点（Ctrl+D）、全选（Ctrl+A），历史保留本次会话最近 60 步。
- 自动保存到当前浏览器，刷新或切换页面后恢复。仅本地保存，不同步到服务器。

## AI 视频创作架构

「AI 视频创作 · MVP 系统架构」地址为 `/#architecture`，可从顶部「系统架构」打开。顶部「自由思维图」切换至原来的编辑器（`/#mindmap`），已有导图仍使用原来的本地保存空间。

架构分为素材理解、导演决策、本地执行三层：

```text
用户 Prompt → 素材分析 Prompt / 导演 Prompt

素材 → Metadata 存在？
       ├─ NO  → 多模态 AI 分析原素材 → 生成并存储元数据
       └─ YES → 读取已有元数据
                    ↓
            Asset Metadata → LLM Director → EditScript JSON
                                               ↓
                                     Remotion → MP4
```

紫色虚线表示 Prompt 控制，彩色实线表示数据流，灰色虚线表示 Remotion 按脚本引用读取原始素材。第一版导演只读取元数据，不重复观看原始视频。

- 「首次分析 / 复用缓存」切换两条路径的高亮。
- 点击节点查看职责、输入输出和结构化数据示意。
- 「开始演示」按六个阶段自动聚焦，每步停留 5.5 秒；支持暂停、切换、方向键和 Esc 退出。
- 节点可以拖动，「恢复布局」回到默认架构布局；窗口尺寸变化时自动适应画布。
- 「导出架构」导出节点、坐标和带类型的连接关系 JSON。架构 JSON 与自由思维图 JSON 使用不同的数据结构。

此页面用于展示系统设计与动画讲解，AI 模型调用、缓存服务和视频渲染由后续工程实现。

## 启动

需要 Node.js 22.12+。在项目目录运行：

```powershell
npm install
npm run dev
```

打开终端显示的地址，默认是 http://localhost:5173 。依赖已安装的情况下直接运行 `npm run dev` 即可。

```powershell
npm run build   # TypeScript 检查并构建到 dist/
npm run lint    # 静态检查
npm run preview # 预览生产构建
```

## 使用

- **绘制**：选择节点，点击左侧「添加子分支」。从右上角文件菜单选择「新建导图」，可以从一个中心主题开始。
- **编辑**：选择节点，在左侧修改名称、备注、分支颜色；双击节点可直接聚焦编辑框。分支和中心主题的备注会显示在画布里，叶子节点的备注保存在编辑面板中。
- **布局**：拖动节点调整位置，拖动画布平移，滚轮缩放。「整理布局」会生成双侧树形结构，按实际节点高度避开重叠。
- **动画**：「样式与动画」可以开关流动光点、节点轻盈浮动，重播节点入场效果，并设置演示每步停留 2–10 秒。
- **演示**：点击「开始演示」先展示全景，再依次聚焦一级分支。播放栏可以暂停、切换或跳到指定步骤，最后一个主题停留结束后会自动暂停。退出后返回编辑界面。
- **保存**：导图自动保存在当前浏览器的 localStorage，同一地址刷新可恢复。文件菜单支持 JSON 导入与导出，便于备份和迁移。
- **撤销**：可撤销编辑、拖动、删除、新建和导入，最多保留 80 步历史；历史仅在本次页面会话内保留。

| 快捷键 | 操作 |
| --- | --- |
| Tab（画布聚焦时） | 添加所选主题的子分支 |
| Delete / Backspace（非输入状态） | 删除所选主题及子分支；中心主题受保护 |
| Ctrl / Cmd + Z | 撤销 |
| Ctrl / Cmd + Shift + Z，或 Ctrl + Y | 重做 |
| Space（非输入状态） | 播放 / 暂停演示 |
| ← / →（演示时） | 上一个 / 下一个主题 |
| Esc | 退出演示或关闭帮助 |

## 代码位置

```text
src/App.tsx                页面、主题节点、动画连线、编辑和演示交互
src/FlowchartBoard.tsx     流程图节点、自由连线、文字编辑和本地保存
src/FlowchartBoard.css     流程图画布与工具条样式
src/flowchart.ts           流程图数据、旧格式兼容和 JSON 校验
src/useFlowchartHistory.ts 流程图撤销 / 重做历史
src/ArchitectureBoard.tsx  架构画布、分支高亮、节点说明和阶段演示
src/ArchitectureBoard.css  系统分层、架构节点、连接标签与演示面板
src/architecture.ts        AI 视频创作架构节点、关系、职责和讲解步骤
src/App.css                页面风格、节点入场与浮动动画、响应式布局
src/mindmap.ts             导图类型、示例数据、树布局与导入校验
src/useDocumentHistory.ts  撤销 / 重做与拖动历史
src/index.css              全局基础样式和字体
```

导图由一个中心主题和多层子主题构成。每个主题通过 `parent` 字段关联父主题，`side` 指定所属左右分支，`position` 保存画布坐标；连线由父子关系生成。导入校验会拒绝重复 ID、缺失父节点、循环引用和多个中心主题，最多支持 500 个节点、2 MB 文件。

无需后端即可运行。浏览器地址不同（例如 `localhost` 和 `127.0.0.1`），本地保存空间也不同；可以用 JSON 文件迁移导图。界面以桌面和笔记本浏览器为主，最小画布窗口宽度为 760px。

## 已验证

通过生产构建和 lint；使用 Playwright 在 Chromium 中检查了：添加、编辑、颜色修改、本地保存与刷新恢复、删除、撤销与重做、拖动及拖动撤销、长文字自动布局、动画开关、演示自动推进 / 暂停 / 切换 / 退出、JSON 导出与导入、循环引用文件拦截，以及 1280px 视口布局。

架构页额外验证了缓存场景切换、节点职责说明、连线动画开关、阶段聚焦、自动播放与暂停、架构导出，以及切换页面后编辑器内容保留。

动画实现参考 React Flow 官方的 [自定义边](https://reactflow.dev/learn/customization/custom-edges) 和 [连线动画示例](https://reactflow.dev/examples/edges/animating-edges)。
